Projeto desenvolvido em Java para a disciplina de Programação I (2026/1), utilizando conceitos de Programação Orientada a Objetos (POO), com o objetivo de desenvolver um sistema funcional para um Pet Shop.
O sistema permite o cadastro, gerenciamento e exclusão de clientes, pets, funcionários e produtos, além de possibilitar a interação entre as diferentes classes do sistema.
O projeto aplica conceitos fundamentais de POO, como encapsulamento, herança, polimorfismo e interação entre classes

Todas as funcionalidades do sistema são acessadas por meio de um menu numérico com 17 opções, incluindo:
- cadastro e exclusão de clientes, pets, funcionários e produtos
- busca por raça
- busca por salário de funcionários
- consulta do número de pacientes por espécie, entre outras operações.

As informações cadastrais são inseridas pelo usuário por meio do teclado. 
De acordo com as opções escolhidas, as informações pedidas via terminal se alteram, como: e acordo com a espécie do pet cadastrada, o sistema solicita informações específicas relacionadas ao seu tipo, e, no cadastro de funcionários, após o preenchimento das informações básicas, é possível cadastrar o funcionário como Gestor ou Veterinário, cada um com suas características específicas.

O sistema também permite o cadastro de produtos, recebendo via teclado as informações necessárias, como nome, descrição e valor. Os produtos podem incluir materiais utilizados em banho e tosa, medicamentos, brinquedos, entre outros itens disponíveis no Pet Shop.

Por fim, o sistema conta com uma classe responsável pelo gerenciamento dos produtos, armazenando e controlando os produtos disponíveis no Pet Shop.
